# Cowrie SSH Honeypot Deployment

## Overview
Cowrie is an SSH and Telnet honeypot used to monitor and record suspicious login attempts and attacker activities.

## Environment
- Operating System: Kali Linux
- Honeypot: Cowrie
- SSH Port: 2222
- Sensor Name: Kali

## Implementation
- Installed and configured Cowrie.
- Started the honeypot service.
- Monitored SSH connection attempts.
- Collected attacker activity logs.
- Analyzed suspicious commands and events.

## Log Analysis
Cowrie generates JSON log files containing information about SSH sessions, source IP addresses, login attempts and executed commands.

## Purpose
The honeypot helps understand attacker behavior and supports cybersecurity threat intelligence analysis.

## Security Note
This documentation describes the project setup. Sensitive credentials and private system information are not included.
