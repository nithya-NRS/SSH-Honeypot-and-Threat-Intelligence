# SSH Honeypot and Threat Intelligence System

## Project Overview
This project focuses on deploying an SSH Honeypot using Cowrie and integrating it with Splunk SIEM for security monitoring and threat analysis.

The system captures suspicious SSH activities, analyzes attacker behavior, collects threat intelligence and displays security information through a custom web dashboard.

## Technologies Used
- Kali Linux
- Cowrie SSH Honeypot
- Splunk SIEM
- Python
- HTML, CSS and JavaScript

## Key Features
- SSH attack monitoring
- Attacker activity analysis
- Source IP identification
- Suspicious command detection
- Threat intelligence collection
- Custom security dashboard

## Project Modules
- SSH Honeypot Deployment
- SIEM Log Monitoring
- Threat Intelligence Analysis
- Dashboard Visualization

## Project Objective
To understand SSH-based attacks and gain practical experience in cybersecurity monitoring, threat detection and digital investigation.
